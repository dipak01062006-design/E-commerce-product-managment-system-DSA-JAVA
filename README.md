#E-Commerce Product Management System
A simple Java-based E-Commerce Product Management System developed using Object-Oriented Programming (OOP) concepts. This application allows users to manage products by adding, displaying, searching, updating, and deleting product details.

##Features
- Add new products with ID, name, category, price, and quantity.
- Display all available products.
- Search products using Product ID.
- Update existing product details.
- Delete products from the system.
- Console-based user interface.
- Product price displayed in Indian Rupees (₹).

##Technologies Used

- **Programming Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Data Structure:** ArrayList
- **IDE:** VS Code / IntelliJ IDEA / Eclipse

##OOP Concepts Used

- Encapsulation
- Classes and Objects
- Constructors
- Methods
- Data Handling using ArrayList

##🎯Objective

The main objective of this project is to develop a simple product management system that helps users efficiently manage e-commerce product information.
